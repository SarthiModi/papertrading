# TradeHawk

**A Concurrent Paper Trading Simulator for Real-Time Order Processing**

## Overview

TradeHawk is a web-based paper trading application that allows users to trade stocks using virtual money. It demonstrates **Operating System and DBMS concepts** through concurrent order processing and consistent data management.

## Key Features

* Virtual wallet and simulated stock prices
* Buy/Sell order placement
* Portfolio and Profit/Loss tracking
* FCFS and Priority Scheduling
* Producer–Consumer model
* Synchronization using locks/semaphores
* Deadlock prevention
* LRU/LFU cache management
* Database transactions and concurrency control

## Technologies

* **Frontend:** React
* **Backend:** Node.js / Express
* **Database:** PostgreSQL / MySQL
* **Cache/Queue:** Redis

## Objective

To provide a risk-free trading environment while demonstrating **OS concepts** such as scheduling, synchronization, and resource management, along with **DBMS concepts** such as normalization, transactions, and concurrency control.
